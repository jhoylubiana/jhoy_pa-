O que é GIT e GitHub

GIT

O GIT é um sistema de controle de versões que permite acompanhar as alterações realizadas nos arquivos de um projeto.

Com ele, podemos registrar alterações, recuperar versões anteriores e trabalhar em Equipe.

GitHUB

O GitHub é uma plataforma online que permite armazenar e compartilhar repositórios git

Por meio dele, podemos compartilhar projetos, colaborar com outros desenvolvedores e visualizar o histórico de Alterações

Comandos para Praticar

Clique em um comando para abrir sua explicação. No teclado, use Tab e Enter

1. git init - iniciar um Repositorio

execute na pasta do projeto para começar controlar as suas versões

Git init
2. Git status - conferir as alteraçoes

mostra quais arquivos foram modificados e quais estão preparados para o proximo commit.

Git status
3. Git add - preparar os arquivos

prepara as alterações dos dois arquivos para o proximo commit. Ainda não cria uma versão

Git add index.html style.css
4. Git commit - registra uma versão

registra as alteraçoes preparadas. Escreva uma menssagem que expliquem oque voce fez

Git commit -m "Adiciona area de estudos"
5. Git log - consultar o historico

exibe os commits de forma resumida, com um registro por linha.

Git log --oneline
6. Git push - enviar para o GitHub

envia os commits para o repositorio remoto. Este exemplo exige um remoto chamado origin, uma branch chamada main e autenticação configurados com o professor.

Git push -u origin main
